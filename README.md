# 💈 Barbearia Elite

Site institucional moderno para barbearia, com design elegante, responsivo e funcional.

---

## 🚀 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de criar uma presença digital profissional para uma barbearia, permitindo que clientes encontrem informações, serviços e entrem em contato facilmente.

---

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

---

## ✨ Funcionalidades

- 🌗 Modo Dark/Light (alternável)
- 📱 Layout responsivo
- 💬 Botão de contato via WhatsApp
- 💈 Exibição de serviços (corte, barba, combo)
- 📍 Informações de contato e localização
- 📲 Design moderno e intuitivo
